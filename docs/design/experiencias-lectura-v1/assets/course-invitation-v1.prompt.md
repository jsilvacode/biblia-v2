## Revisión visual

- Panorámica 2:1: figura a la derecha, espacio azul/lila utilizable para texto HTML a la izquierda.
- Rostro cálido, túnica marfil, manos abiertas sin anomalías evidentes a esta escala.
- Pintura serena con flores, tonos sobrios; no contiene texto, logotipos ni marcas.
- Para móvil, conservar rostro y manos: preferir una franja de imagen sobre el texto o un recorte con `object-position: 76% center`; no colocar texto sobre el rostro.
- Para texto blanco sobre el lado izquierdo, usar velo azul oscuro desde CSS y verificar contraste del conjunto. La imagen no debe contener tipografía rasterizada.
- Asset maestro para mockups. Optimizar a formatos web y verificar presupuesto de peso antes de usar en producción.
