## Decisión de etapa 6A

## Evidencia que cambiaría esta decisión

Para habilitar `6B` o `6C` hace falta una autorización escrita o una licencia pública verificable que cubra **esa edición en español** y permita servir el texto en web, transformarlo a JSON por capítulo, publicar el repositorio si corresponde y permitir la caché offline planteada. La evidencia debe indicar titular, alcance, versión/edición, URL estable y fecha; si procede, conservar el permiso privado fuera del repositorio público y publicar sólo la atribución autorizada.

Una licencia de un descargador, scraper o repositorio de código no basta. Tampoco basta que la obra sea accesible sin pago o que la autora haya fallecido hace más de un siglo: la traducción y la edición concretas pueden tener derechos propios.
