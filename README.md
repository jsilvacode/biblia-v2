# Santa Biblia

[Santa Biblia](https://santabiblia.cloud) es una aplicación web progresiva
creada para acompañar la lectura bíblica diaria con una experiencia serena,
clara y accesible.

## La experiencia

- Lectura bíblica en español, inglés y portugués.
- Comentario bíblico, modo inmersivo y preferencias de lectura.
- Promesas diarias y el plan anual Reavivados por su Palabra.
- Guía de consulta bíblica y estudio La Fe de Jesús.
- Búsqueda, favoritos, destacados y notas temáticas.
- Instalación en dispositivos compatibles y lectura sin conexión.
- Enlaces de versículos con tarjetas sociales personalizadas.

## Privacidad

Las preferencias, lecturas guardadas, destacados y notas se conservan
localmente en el dispositivo. La aplicación utiliza Vercel Web Analytics para
obtener estadísticas agregadas de navegación sin crear perfiles personales de
los lectores.

## Contenidos y atribuciones

Las traducciones bíblicas, el comentario y los materiales de estudio conservan
las atribuciones y condiciones de sus respectivos titulares. Los créditos del
estudio *La Fe de Jesús* se encuentran en
[`src/content/la-fe-de-jesus/README.md`](src/content/la-fe-de-jesus/README.md).
